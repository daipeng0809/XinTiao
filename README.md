# 信息调试助手（XinTiao）

一款基于 .NET 10 + Avalonia 的跨平台串口 / 网络调试工具，支持 Windows x64 与银河麒麟 V10（Linux arm64），
采用 NativeAOT 发布，目标机器无需安装 .NET 运行时。

当前版本：**V1.1.0**

---

## 一、功能清单

### 1. 连接方式（左侧页签）

| 方式 | 说明 |
| --- | --- |
| 串口 | 自动枚举本机串口，可设置波特率、校验位、数据位、停止位 |
| TCP 客户端 | 指定本地 IP / 端口（本地端口 0 表示系统自动分配）主动连接对端 |
| TCP 服务端 | 监听本地端口，允许多个客户端接入；收到多个客户端的数据汇总显示，发送时广播给所有客户端 |
| UDP | 绑定本地端口收发，运行中可随时修改对端 IP / 端口，修改立即生效 |

- 同一时刻只允许一个通道处于打开状态，打开后其余页签自动锁定，避免多通道混收。
- 右上角状态徽标显示当前连接状态（未连接 / 已打开 / 监听中 / 正在断开），并显示串口名、对端地址或客户端数量。

### 2. 接收区

- 文本显示 / HEX 显示一键切换。
- 可选择是否在每条数据前显示时间戳（精确到毫秒）。
- 接收内容鼠标可选中复制，接收区自动滚动到最新内容。
- 底部状态栏实时统计累计接收、发送的字节数，可一键清空接收区 / 发送区。

### 3. 发送区

发送区标题右侧是 **单条数据 / 多行数据** 两个页签（紧贴标题，不单独占一行），公共选项位于发送区右上角。

公共选项：

- **加回车换行**：勾选后，发送内容末尾自动追加 CR LF（HEX 显示为 `0D 0A`），文本 / HEX 发送均生效。
- **文本发送 / HEX 发送**：单条数据的发送方式（HEX 输入支持 `AA BB 11 22` 这种带空格的写法，并会对非法字符、奇数长度给出提示）；切到多行数据页时该开关会置灰，由每行自己的 HEX 勾选决定。

单条数据页：

- 一个多行输入框，输入内容后点击“发送”。
- 可按指定间隔（毫秒）定时发送，再次点击“停止发送”结束。

多行数据页：

- 每一行是独立的一条待发数据，每行都是单行高度（输入框、HEX、间隔、定时发送、发送、删除在同一行），尽量节省空间；
- 每行可单独设置：发送内容、是否 HEX、定时发送间隔（毫秒）。
- 每行都有“发送”“定时发送 / 停止发送”“删除”按钮，多行之间互不影响，可同时运行多个定时任务。
- 数量可随时增减：“增加一行”“删除末行”，或直接删除指定行（至少保留一行）。
- 行数较多时可上下滚动查看。

### 4. 其他

- 亮色 / 暗色主题切换。
- 所有参数与输入内容实时保存（停顿 500ms 自动落盘），下次启动自动恢复：串口参数、TCP / UDP 参数、显示方式、发送方式、定时间隔、加回车换行、**单条发送内容**、多行发送内容与每行设置、当前所在页签、主题等。
- 配置文件优先写入程序目录 `Config/AppConfig.json`；安装目录只读（如 `/opt`、`Program Files`）时自动回退到用户目录：
  - Windows：`%APPDATA%\XinTiao\AppConfig.json`
  - Linux：`~/.config/XinTiao/AppConfig.json`

## 三、使用说明

1. 左侧选择连接方式并填写参数，点击“打开串口 / 连接 / 开始监听 / 打开”。
2. 右上角状态变为绿色并显示连接信息，说明连接成功。
3. 在发送区选择“单条数据”或“多行数据”，输入内容后发送；需要协议结尾带回车的场景，勾选“加回车换行”。
4. 接收区可按文本 / HEX 查看数据，勾选“显示时间”可看到每条数据的接收时刻。
5. 关闭窗口时会自动关闭并释放当前通道。

小提示：

- HEX 发送要求去掉空格后字符数为偶数，且只能是 `0-9 / A-F / a-f`。
- TCP 服务端尚未有客户端接入时发送会给出提示，先让客户端连上再发送。
- 定时发送启动前会校验内容与连接：HEX 格式非法、服务端还没有客户端接入时不允许启动；运行中内容变成非法 HEX（或被清空）时，该行 / 单条的定时会自动停止，避免“看着在发、实际没发”。
- 多行页的定时发送在连接断开或关闭通道时自动停止。

## 四、Linux（银河麒麟）安装

程序发布目录中已包含 `install.sh` 与 `XinTiao.desktop` 模板。

```bash
# 1. 进入程序所在目录（把程序、Assets 目录、install.sh 放在一起）
cd /opt/xintiao

# 2. 赋予执行权限（程序与脚本）
chmod +x 信息调试助手 install.sh

# 3. 生成桌面启动文件并安装到应用菜单（当前用户）
bash install.sh

# 或者：安装给所有用户
sudo bash install.sh

# 也可以手动指定程序路径
bash install.sh /opt/xintiao/信息调试助手
```

脚本会做这些事：

- 自动识别同目录下的可执行程序（也可通过第一个参数指定）；
- 自动识别图标（优先 `Assets/wk.png`，其次 `Assets/wk-256x256.ico`）；
- 在程序目录生成 `XinTiao.desktop`，`Exec` / `Icon` / `Path` 全部为程序当前真实绝对路径；
- 复制到 `~/.local/share/applications`（root 用户为 `/usr/share/applications`）并刷新菜单缓存。

安装完成后，在应用菜单中搜索“信息调试助手”或“XinTiao”即可启动。

> 如果脚本是从 Windows 复制到 Linux 的，出现 `$'\r': command not found` 之类错误，先执行：
> `sed -i 's/\r$//' install.sh` 再运行。

## 五、构建与发布

```bash
# 本地调试运行
dotnet run

# Windows x64 发布（NativeAOT）
dotnet publish -c Release -r win-x64 -p:PublishAot=true

# 银河麒麟 V10（linux-arm64 / linux-x64）发布，需在目标架构机器上执行
# 依赖：sudo apt install clang lld zlib1g-dev
dotnet publish -c Release -r linux-arm64 -p:PublishAot=true
```

发布目录会同时带上 `Config/`、`Assets/`、`install.sh`、`XinTiao.desktop` 与本说明文件。
